PoliSync

An insurance claims management platform.

PoliSync is a full-stack insurance claims management web application.

Customers can submit and view their own submitted insurance claims, while administrators can view policies, view and manage submitted claims through a dedicated dashboard.

Live Demo GitHub

Using the Application

Customer Flow

  1. Log in using seeded Customer credentials
  2. Submit a new insurance claim
  3. View previously sumbitted claims
  4. Log out

Administrator Flow

  1. Log in using seeded Administrator credentials
  2. View all insurance policies
  3. View all submitted claims
  4. Open a claim to view it's details
  5. Update the claim status or delete the claim
  6. Log out

Concepts Demonstrated

  • REST API development with ASP.NET Core
  • Authentication (Cookie-based)
  • Authorisation (Role-based - Customer & Administrator roles)
  • Dependency Injection & Layered Architecture (Repository-Service-Controller Pattern)
  • Seeding Data & Database Migrations using SQLite & Entity Framework Core
  • Hosting on Railway

Tech Stack

  • Backend: C#, .NET10, ASP.NET Core Web API, Entity Framework Core, SQLite
  • Frontend: Semantic HTML5, PicoCSS, Vanilla JavaScript
