DawaLens

Search for a drug, review the details, send it to a patient.

DawaLens is a web application that searches the OpenFDA API for drug label information, caches results locally, generates a downloadable PDF from the results and allows you to send it on email.

Live Demo GitHub

Using the Application

  1. User searches for a drug
  2. Backend checks the SQLite cache
  3. If uncached, data is fetched from the OpenFDA API, deserialized into a DTO, and then cached
  4. Result is returned to the frontend
  5. A PDF can be generated from the result
  6. The PDF can be emailed to a given address

Concepts Demonstrated

  • Consumption of a free, public API (OpenFDA API)
  • Deserializing nested & variable JSON responses into usable DTOs
  • Caching with SQLite & Entity Framework Core
  • Backend Document Generation (PDF document with QuestPDF and QuestCompanion)
  • External Integration with email sending service (Resend)
  • Hosting on Railway

Tech Stack

  • Backend: C#, .NET10, ASP.NET Core Web API, Entity Framework Core, SQLite, QuestPDF, Resend
  • Frontend: Semantic HTML5, PicoCSS, Vanilla JavaScript
